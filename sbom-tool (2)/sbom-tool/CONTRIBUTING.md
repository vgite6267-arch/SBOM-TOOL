# Contributing to SBOM Guardian

Thank you for your interest in contributing to SBOM Guardian!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/sbom-guardian.git
   ```
3. **Create a branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make your changes** and test locally by running `python app.py`.
5. **Commit your changes** with clear, descriptive messages:
   ```bash
   git commit -m "Add feature: support for Maven pom.xml manifests"
   ```
6. **Push to your fork** and submit a **Pull Request**.

## Code Style
- Follow PEP 8 guidelines for Python code.
- Maintain clean, responsive CSS and semantic HTML.
